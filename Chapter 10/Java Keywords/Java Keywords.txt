Java Keywords and their meanings Class – A blueprint for creating objects. Object – An instance of a class. Method – A block of code that performs a task. Variable – Stores data in a program. Data Type – Defines the type of data (int, String, etc.). int – Stores whole numbers. double – Stores decimal numbers. char – Stores a single character. String – Stores text. boolean – Stores true or false values. if – Executes code based on a condition. else – Runs when the if condition is false. switch – Selects one block from many options. for – Loop that repeats a set number of times. while – Loop that runs while a condition is true. do-while – Runs at least once before checking condition. break – Stops a loop or switch. continue – Skips to the next loop iteration. Array – Stores multiple values in one variable. Constructor – Initializes objects when created. this – Refers to the current object. static – Belongs to the class, not instances. final – Prevents modification. void – Indicates no return value. return – Sends a value back from a method. public – Accessible from anywhere. private – Accessible only within the class. protected – Accessible within package and subclasses. package – Groups related classes. import – Brings in other classes or packages. interface – Defines methods without implementation. abstract – Defines incomplete classes or methods. extends – Inherits from another class. implements – Uses an interface. Inheritance – One class gets features of another. Polymorphism – Same method behaves differently. Encapsulation – Hides data inside classes. Exception – An error during program execution. try – Tests code for exceptions. catch – Handles exceptions. finally – Runs after try/catch block. throw – Creates an exception. throws – Declares exceptions a method may produce. Thread – A unit of execution in a program. Runnable – Interface for creating threads. synchronized – Controls access in multithreading. File – Represents file handling operations. Scanner – Reads input from users. System.out.println – Prints output to console. Main Method – Entry point of a Java program. JVM – Runs Java bytecode. JRE – Provides libraries to run Java programs. JDK – Tools for developing Java programs. Garbage Collection – Frees unused memory. Lambda Expression – Short way to write functions. Stream API – Processes collections of data. Collections Framework – Pre-built data structures.
